# Лабораторная работа №1. Введение в Python

Решения заданий лабораторной работы по дисциплине «Теория алгоритмов».
Одиннадцать скриптов на базовых конструкциях языка: числа, срезы строк,
списки, кортежи, множества, словари и вложенные структуры данных.

## Требования

Python 3.10 или новее. Проверить установленную версию:

    python --version

## Установка

Клонировать репозиторий и перейти в каталог лабораторной:

    git clone https://github.com/urifar/Alg_theory.git
    cd Alg_theory

Внешних зависимостей нет, устанавливать через pip ничего не нужно.

## Структура

| Файл | Что отрабатывается | Результат работы |
|------|--------------------|------------------|
| 00_distance.py | словари, вложенные циклы | словарь расстояний между городами |
| 01_circle.py | арифметика, round, сравнения | площадь круга, проверка точек |
| 02_operations.py | приоритет операций и скобки | выражение из чисел 1–5, равное 25 |
| 03_favorite_movies.py | индексы и срезы строк | четыре фильма из одной строки |
| 04_my_family.py | списки, список списков | рост отца и суммарный рост семьи |
| 05_zoo.py | методы списка | insert, extend, remove, index |
| 06_songs_list.py | список списков и словарь, float | суммарное время звучания песен |
| 07_secret.py | срезы с шагом, обратные срезы | расшифрованная фраза |
| 08_garden.py | множества | объединение, пересечение, разности |
| 09_shopping.py | вложенные структуры, sorted | два магазина с минимальной ценой |
| 10_store.py | вложенные структуры | стоимость товара на складе |

## Запуск

Каждый скрипт запускается независимо:

    python 00_distance.py
